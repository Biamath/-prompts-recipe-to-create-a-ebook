# -prompts-recipe-to-create-a-ebook
Projeto do bootcamp da DIO


       C#: O Código da Matriz
       

Ação
	Prompt
Título	Crie um título de um ebook sobre o tema de C#, o ebook é do nicho de programação e o subnicho é de C#, o título deve ser épico e curto, e tenha uma temática do filme "Matriz" no título, me liste 5 variações de títulos
Conteúdo	Faça um texto para ebook , com foco em C#, listando os principais componentes em c# com exemplos em código {REGRAS} Explique sempre de uma maneira simples Deixe o texto enxuto, Sempre traga exemplos de código em contextos reais , sempre deixe um título sugestivo por tópico
